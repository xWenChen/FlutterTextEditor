# 数据搬家说明

**文档版本**：1.0

**功能解释**：数据搬家功能可以将当前设备的内容搬到另外一台支持搬家的设备上。

**技术原理**：应用搬家目前采用的技术是Wi-Fi P2P(Wi-Fi 直连)。

**生效条件**：如果想要搬家功能生效，需要打开手机设置里的Wi-Fi开关和定位开关(可通过通知栏设置)。

## 常见问题

### 问题1：设备无法被发现。

**问题**：另一台Android设备开启了Wi-Fi，与当前设备处于同一个Wi-Fi下。且打开了位置信息。但是当前设备无法搜索到该设备。

**回答**：一个常见的原因是：另一台手机必须打开系统的“Wi-Fi直连(Wi-Fi Direct)”设置页面，此时Android系统才会把底层 Wi-Fi P2P 广播设为"可被发现"状态。

**建议**：打开另一台手机的：设置 -> Wi-Fi -> 高级设置/更多设置 -> Wi-Fi 直连 (Wi-Fi Direct)，停留在该页面。再进行设备搜索。
